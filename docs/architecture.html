Hermes ↔ Codex 任务编排架构

macOS · Hermes gateway（默认 runtime）+ codex-job-harness · codex-cli 0.167.0 · 2026-11-07

分层职责

  • • Hermes：决定做什么、拆任务、验收、通知
  • • 插件：把决定变成 codex 任务，返回 job_id
  • • 文件目录：当作任务队列与状态机
  • • codex：真正改/读代码、跑命令、产结论

为什么不用 SDK / 常驻 daemon

  • • SDK 只是包装同一个 codex CLI，多一层 Node 依赖
  • • app-server daemon 是 experimental，且线程锁更脆
  • • 现在这层崩溃可重试、状态可审计、无需常驻进程

运维要点

  • • 插件更新后必须 disable+enable 才会重载
  • • 改 .env 后新会话生效，无需重启网关
  • • 通知上限 60s 一条链路；失败只报一次
